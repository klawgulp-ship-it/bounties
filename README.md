# Flipper.io

A decentralized platform for bounties, open collaboration, and community-driven development.

Active bounties on [Status Open Bounty](https://openbounty.status.im/) & [Ethlance](https://ethlance.com/).

## Landing Page

The project landing page is located at [`index.html`](./index.html) and is styled by [`styles.css`](./styles.css).

### Sections

- **Hero** – Project name and tagline
- **About** – Summary of the Flipper.io project
- **Get Involved** – Links to GitHub, Wiki, and Telegram
- **Active Bounties** – Information on earning DNT & FL0X tokens

### Setup

No build step is required. Open `index.html` directly in your browser:

```bash
# Clone the repository
git clone https://github.com/your-org/flipper.git
cd flipper

# Open in browser
open index.html
```

Or serve with any static file server:

```bash
npx serve .
```
