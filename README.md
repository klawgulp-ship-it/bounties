## Landing Page

A landing page for [Flipper.io](https://flipper-io.github.io) is available at `index.html`.

### Viewing locally

1. Clone the repository:
   ```bash
   git clone https://github.com/flipper-io/bounties.git
   cd bounties
   ```
2. Open `index.html` directly in your browser, or serve it with any static file server:
   ```bash
   npx serve .
   ```
3. Navigate to `http://localhost:3000` (or the port shown in your terminal).
