# Proposal

## Overview

FL0X is a decentralized project aimed at building open-source tooling and infrastructure for the community. This document outlines the core proposal behind FL0X.

## Goals

- Build transparent, community-governed tooling.
- Reward contributors fairly through a bounty system.
- Foster adoption of the FL0X token within the ecosystem.

## How It Works

1. Community members identify work that needs to be done.
2. Bounties are created and denominated in DNT and/or FL0X.
3. Contributors pick up bounties, complete the work, and submit for review.
4. Upon approval, bounties are paid out.

## Governance

Decisions about the project direction are made collaboratively by the community. Proposals can be submitted via the project repository.
