# Active Bounties

The following bounties are currently open and available for contributors.

## How to Claim a Bounty

1. Find a bounty you want to work on in the list below.
2. Comment on the associated GitHub issue to express your interest.
3. Complete the work and submit a pull request referencing the issue.
4. Once merged and approved, the bounty will be paid out.

## Open Bounties

| [#1 Create Wiki](https://github.com/) | Deploy boilerplate MkDocs wiki | 300 DNT + 300 FL0X |

!!! note
    This table is updated as new bounties are added. Check back regularly for new opportunities.

## Bounty Rules

- Each bounty can only be claimed by one contributor unless otherwise stated.
- Work must meet the requirements described in the linked issue.
- Payouts are made after the pull request is reviewed and merged.
- Bounties are denominated in DNT and/or FL0X tokens.
