# How to Add FL0X Token

This guide walks you through adding the FL0X token to your Ethereum-compatible wallet (e.g., MetaMask).

## Token Details

| Field | Value |
|-------|-------|
| Token Name | FL0X |
| Token Symbol | FL0X |
| Network | Ethereum Mainnet |
| Decimals | 18 |

> **Note:** Replace the contract address below with the official FL0X contract address once deployed.

## Adding FL0X to MetaMask

1. Open **MetaMask** and ensure you are connected to the **Ethereum Mainnet**.
2. Scroll down in the Assets tab and click **"Import tokens"**.
3. Select **"Custom Token"**.
4. Enter the FL0X **contract address** in the Token Contract Address field.
5. The Token Symbol (`FL0X`) and Decimals (`18`) should populate automatically.
6. Click **"Add Custom Token"**, then **"Import Tokens"** to confirm.

## Adding FL0X to Other Wallets

Most ERC-20 compatible wallets support adding custom tokens. Look for an option such as:

- **"Add Token"** or **"Import Token"**
- **"Custom Token"** or **"Manual Token Entry"**

Enter the FL0X contract address along with the symbol and decimals listed above.

## Verifying the Token

Once added, you can verify the FL0X token on [Etherscan](https://etherscan.io) by searching for the contract address.
