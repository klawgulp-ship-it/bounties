# How to Add FL0X Token

This guide explains how to add the FL0X token to your wallet so you can send, receive, and manage your FL0X balance.

## Prerequisites

- A compatible Web3 wallet (e.g., MetaMask, Trust Wallet)
- The FL0X token contract address (see below)

## FL0X Token Details

| Field            | Value                          |
|------------------|--------------------------------|
| Token Name       | FL0X                           |
| Token Symbol     | FL0X                           |
| Decimals         | 18                             |
| Contract Address | `0x0000000000000000000000000000000000000000` |
| Network          | Ethereum Mainnet               |

!!! warning
    Always verify the contract address from an official source before adding any token to your wallet.

## Adding FL0X to MetaMask

1. Open MetaMask and ensure you are on the correct network.
2. Click **Import tokens** at the bottom of the Assets tab.
3. Select **Custom Token**.
4. Paste the FL0X contract address into the **Token Contract Address** field.
5. The **Token Symbol** and **Token Decimal** fields should populate automatically.
6. Click **Add Custom Token**.
7. Click **Import Tokens** to confirm.

FL0X will now appear in your MetaMask wallet.

## Adding FL0X to Trust Wallet

1. Open Trust Wallet and tap the icon in the top right to manage tokens.
2. Tap **Add Custom Token**.
3. Select the correct network.
4. Paste the FL0X contract address.
5. Fill in the token name, symbol, and decimals if not auto-populated.
6. Tap **Done**.

FL0X will now appear in your Trust Wallet.

## Troubleshooting

- **Token not found automatically:** Enter the token details manually using the table above.
- **Wrong network:** Make sure your wallet is connected to the correct network before adding the token.
- **Balance not showing:** Ensure you have received FL0X to your wallet address before expecting a balance.
